# Implementation plan: SHA-298 revoke guidance on a resumed revoke

SHA-294 keeps only a safe summary of a revoke error when the process never
held the replacement (after the overlap window, or `--wait` in a new
process). That also dropped rotate's own advice ("set ROTATE_NPM_TOKEN to an
`npm login` session token", "set OPENAI_ADMIN_KEY ..."), which lived in the
same string as the upstream text. The resumed path is the usual one, so
the advice must survive it.

## Decisions

- Guidance is a separate, typed value: `ProviderError::Guided { error,
  guidance: &'static str }`, built with `err.with_guidance(..)`. A
  `&'static str` cannot be built from upstream or runtime text, so it is
  safe to keep where the upstream text is not. Re-guiding replaces the
  guidance instead of nesting.
- A wrapper variant rather than a field on every variant: about 150 sites
  build `ProviderError`, and only a few revoke errors carry guidance.
- The wrapper is transparent: `Display` is the wrapped error's, and
  `is_retryable` and every `Unsupported` match go through `base()` (or
  `unsupported()`): apply verify and revoke, rollback, and the conformance
  suite.
- The same-process (`Redacted`) path is unchanged: the full redacted text
  already says the same thing.

## Changes

- `src/provider/mod.rs`: the variant and `with_guidance`, `guidance`,
  `base`, `into_base`, `unsupported`.
- `src/apply.rs`, resumed revoke (`UpstreamText::Summary`):
  - failed: `<summary>. <guidance>`;
  - `Unsupported`: revoke by hand with `<guidance> (<summary>)`, where the
    guidance replaces the generic fallback.

  `revoke_error_summary` matches on `base()`.
- `src/provider/npm.rs`: `GUIDE_NO_OPERATOR`, `GUIDE_OPERATOR_IS_LEAKED`,
  `GUIDE_SESSION_TOKEN` (403 on delete, and 401 or 403 on the token list
  during revoke), `GUIDE_OTP`, `GUIDE_OTHER_USER`.
- `src/provider/openai.rs`: `GUIDE_NEEDS_ADMIN` (revoke without an admin
  key), `GUIDE_ADMIN_IS_LEAKED` (admin key equal to the key being rotated),
  `GUIDE_UNDELETABLE`. `admin_key()` keeps the no-key `Unsupported`
  unguided, because create and scope use it too. Without an admin key,
  apply reaches `manual_revoke` (`REVOKE_NEEDS_ADMIN`) before `revoke`, so
  the resumed path already showed that text; T1 now proves it.
- `docs/plans/SHA-294.md`: note that it amended decision D4.
